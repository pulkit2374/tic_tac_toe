

# 🎮 Tic Tac Toe (Console Version)

A simple command-line implementation of the classic Tic Tac Toe game written in Python. This game supports both **Human vs Human** and **Human vs AI** gameplay modes.

---

## 📋 Features

- 3x3 Tic Tac Toe board displayed in the console
- Human vs Human or Human vs AI mode
- Turn-based gameplay with real-time board updates
- Win detection and draw logic
- Score tracking for wins and draws across multiple games

## 🧠 How to Play

- The game board positions are numbered from 1 to 9:

```
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

- Enter the number corresponding to the position where you'd like to place your mark (`X` or `O`).
- First player is always `X`.
